# Carpeta de Assets del Frontend (src/assets/images)

Guarda aquí imágenes procesables por Vite/Webpack.

## Ejemplo de uso con `import`:

```jsx
import logo from '../assets/images/logo.png';
import fachadaImg from '../assets/images/fachada.jpg';

function MiComponente() {
  return <img src={logo} alt="ACEA SAS" />;
}
```
