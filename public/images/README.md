# Carpeta de Imágenes Públicas (ACEA SAS)

Guarda aquí tus imágenes estáticas de alta resolución.

## Ejemplos de uso en el código:

### En componentes React (JSX):
```jsx
<img src="/images/logo-acea.png" alt="ACEA SAS Logo" />
```

### En archivos CSS (index.css):
```css
.hero {
    background-image: url('/images/hero-bg.jpg');
}
```

## Estructura sugerida para tus imágenes:
- `hero-bg.jpg` -> Imagen principal de la sección Hero (Mantenimiento en alturas / Fachadas)
- `manifiesto-img.jpg` -> Imagen de la sección de Manifiesto de Valor
- `fachadas.jpg` -> Tarjeta 1: Mantenimiento de Fachadas y Cubiertas
- `aseo.jpg` -> Tarjeta 2: Aseo Especializado Corporativo
- `obracivil.jpg` -> Tarjeta 3: Obra Civil y Pisos
- `contenedores.jpg` -> Tarjeta 4: Logística y Alquiler de Contenedores
- `trust-bg.jpg` -> Fondo de la sección de estadísticas
